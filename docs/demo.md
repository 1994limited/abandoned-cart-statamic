# The demo shop

[Dog-ear Books with Cargo](https://github.com/1994limited/abandoned-cart-statamic-demo) is a small bookshop built with Abandoned Cart and Cargo. Locally, it runs at `https://abandoned-cart-statamic-demo.test`.

- `php please demo:carts` fills Store → Abandoned Carts with baskets in every state.
- `php please demo:users` sets up the demo's users. It works only on a local site.
- Its emails go to the HELO inbox "Abandoned-Cart-Demo" (see [Emails](emails.md#testing-locally)).

Its README says how to run it.
